# v0.3.0 - Bilingual interface and dark mode

## Highlights

- **Bilingual interface**: English and French are available from the language selector in the navigation bar.
- **Dark mode**: switch between light and dark themes; the choice is remembered on this device.
- **Navigation bar**: quick access to Home, Users, the user menu and the language and theme controls.
- **Release notes**: browse this changelog directly from the navigation bar.

## Improvements

- Accessible labels on icon-only controls and keyboard-friendly navigation.
- Consistent colours in light and dark themes using PrimeVue design tokens.
